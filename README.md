# Contrucciones - Sitio Web Corporativo

Sitio web corporativo y catálogo de servicios desarrollado para [Nombre de la Empresa]. Diseñado para presentar la trayectoria de la empresa, portfolio de obras realizadas y captación de clientes vía formulario directo.

## 🛠️ Tecnologías utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Estructura de Datos:** JSON (para la carga dinámica de proyectos)
* **Formulario de Contacto:** EmailJS / Formspree
* **Despliegue:** Vercel / Netlify

## 🚀 Características

* Diseño responsivo (Mobile First).
* Optimización de rendimiento y carga de imágenes.
* Formulario de contacto directo sin backend propio.
